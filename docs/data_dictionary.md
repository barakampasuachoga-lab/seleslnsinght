# SalesInsight: Data Dictionary

This data dictionary defines every attribute in both the raw and processed retail sales datasets, including canonical name, data type, business definition, and constraints.

---

## Processed Dataset Field Definitions (`sales_cleaned.csv`)

| Field Name | Data Type | Canonical Description | Source Column | Constraints / Rules |
| :--- | :--- | :--- | :--- | :--- |
| `row_id` | Integer | Unique surrogate identifier for transaction line | `Row ID` | Primary Key, > 0 |
| `order_id` | String | Unique commercial identifier for customer order | `Order ID` | Multiple items can share an `order_id` |
| `order_date` | Date | Date when transaction was placed | `Order Date` | ISO-8601 (`YYYY-MM-DD`) |
| `ship_date` | Date | Date when order was dispatched from fulfillment center | `Ship Date` | `ship_date >= order_date` |
| `ship_mode` | String | Delivery logistics class | `Ship Mode` | First Class, Second Class, Standard Class, Same Day |
| `customer_id` | String | Unique identifier assigned to each purchasing entity | `Customer ID` | Natural key |
| `customer_name` | String | Legal name of customer | `Customer Name` | Text, trimmed |
| `customer_segment`| String | Customer market classification | `Segment` | Consumer, Corporate, Home Office |
| `country` | String | Sovereign nation of delivery destination | `Country` | Geographic dimension |
| `city` | String | Destination municipality | `City` | Geographic dimension |
| `state` | String | Destination administrative state/province | `State` | Geographic dimension |
| `postal_code` | String | Destination zip code | `Postal Code` | String to preserve leading zeros |
| `region` | String | Internal sales operational region | `Region` | West, East, Central, South |
| `product_id` | String | Unique product catalog stock identifier | `Product ID` | Catalog identifier |
| `category` | String | Top-level product taxonomic classification | `Category` | Technology, Furniture, Office Supplies |
| `subcategory` | String | Detailed product classification | `Sub-Category` | Chairs, Phones, Binders, Storage, etc. |
| `product_name` | String | Full commercial trade title of product | `Product Name` | Text |
| `sales` | Numeric | Net transaction revenue earned after discount | `Sales` | Currency in USD ($), >= 0 |
| `quantity` | Integer | Total count of units purchased in line item | `Quantity` | Integer, >= 1 |
| `discount` | Numeric | Promotional discount rate applied (0.0 to 1.0) | `Discount` | Floating decimal (e.g. 0.20 = 20%) |
| `profit` | Numeric | Net operating profit or loss generated by line item | `Profit` | Currency in USD ($); negative represents loss |
| `order_year` | Integer | Calendar year of order date | Derived | Extracted from `order_date` |
| `order_month` | Integer | Calendar month index (1-12) | Derived | Extracted from `order_date` |
| `order_quarter` | Integer | Calendar quarter (1-4) | Derived | Extracted from `order_date` |
| `order_year_month`| String | Year and month label formatted as `YYYY-MM` | Derived | Used for time-series aggregation |
| `shipping_days` | Integer | Elapsed days between order date and ship date | Derived | `ship_date - order_date` |
| `profit_margin_pct`| Numeric| Line-item profit margin % = `(profit / sales) * 100` | Derived | Percentage |
| `discount_band` | String | Categorical tier of discount depth | Derived | 0%, 1-10%, 11-20%, 21-40%, Over 40% |
